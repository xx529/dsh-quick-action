## 画板尺寸与关键规格

- 画板：1440 宽；01 高 820，02 高 700，03 高 700，04 高 900，05 高 620，06 高 480，07 高 640。
- 标签条：高 52（darwin 一致）、标签高 46、顶部圆角 23、左右内边距 4+16（滚动容器内边距 16，保证首标签左尾弧不被裁）。
- 标签内容：工作区名 10px/12（实际实现 9px/12）、标题 13px/16、左对齐、状态字形 14px 行内。
- 活动标签：同内容表面色 + 1px 分线色外框（底部不封口）+ 底部 16px 反向圆角弧接入分线。
- 状态字形：运行中=旋转弧、完成未读=实心点、需要你=气泡?/盾牌!/清单（回答/审批/计划评审），完成已读与空闲不显示。
- 动效：运行中 1.1s linear；需要你 2.2s/2.8s `cubic-bezier(.16,1,.3,1)`；完成未读 520ms `cubic-bezier(.34,1.56,.64,1)` 一次性；标签切换 180ms `cubic-bezier(.2,.8,.2,1)`。

- 面板：640 宽，视口垂直居中（四周 2vh / 2vw 内边距），圆角 16，1px 边框，drop shadow；搜索行 58、分组标题 30、行 44、footer 42。

### 行为约定（实现对照）

1. 打开：快捷键 → 遮罩 + 面板居中，焦点进入搜索框；再次按同一键或 esc / 点遮罩关闭。
2. 分组：`已打开` = 标签条顺序（含「新会话」影子标签）；`最近使用` = 其余会话按 `updatedAt` 倒序，排除 blank / 子智能体 / 归档 / 已在已打开组里的会话。
3. 搜索：**标题与工作区名都参与**模糊匹配（子串优先，其次字符子序列），命中字符分别在标题 / 工作区名上高亮；空组隐藏；无结果时展示空态与清除入口。
4. 键盘：↑↓ 移动选中并滚动到可视区，↵ 打开，esc 关闭；点击行等价于 ↵。
5. 行状态点：空闲会话不显示（保留占位，标题对齐）；进行中 / 待审批 / 待回复 / 待评审 / 未读显示彩色点。
6. 打开后：面板立即关闭、切换到目标会话并加入标签条；不弹 toast。
6. 可访问性：`role=dialog` + `aria-modal`，输入框 `role=combobox`，列表 `role=listbox`，行 `role=option` + `aria-selected`，关闭后焦点回到打开前元素。
