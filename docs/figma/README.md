# Figma 原型归档

原型画在 Figma 的本地文件 **`action`** 里，页面名 **`Session Tabs 交互原型`**（7 张画板：01 应用内情境 / 02 标签结构 / 03 状态系统 / 04 动效分镜 / 05 新会话生命周期 / 06 快捷键 / 07 角标版）。

## 本目录内容

| 文件 | 说明 |
|---|---|
| `pdf/01-应用内情境.pdf` … `pdf/07-角标版.pdf` | 每张画板的矢量导出（Figma 直接导出，可放大查看 / 打印） |
| `../prototype/*.png` | 同一批画板的 1× PNG，用于文档与评审 |
| 本 README | 原型结构、关键规格与恢复方式 |

> 没有生成 `.fig` 文件：Figma 的 “Save Local Copy…” 菜单在当前本地文件上点击后没有弹出保存面板（多次尝试均无对话框），因此改为「矢量 PDF + PNG + 规格」归档。若之后能导出 `.fig`，直接放进本目录即可。

## 恢复 / 重开

- 原型文件仍在 Figma 桌面端（本地文件 `action`，团队文件夹 `Team folder`）：打开 Figma → 最近文件 / 本机文件里找 `action`。
- 如果该文件丢失：用 `pdf/` 里的矢量 PDF 或 `../prototype/` 的 PNG 作为唯一依据重建；画板尺寸与关键规格见下。

## 画板尺寸与关键规格

- 画板：1440 宽；01 高 820，02 高 700，03 高 700，04 高 900，05 高 620，06 高 480，07 高 640。
- 标签条：高 52（darwin 一致）、标签高 46、顶部圆角 23、左右内边距 4+16（滚动容器内边距 16，保证首标签左尾弧不被裁）。
- 标签内容：工作区名 10px/12（实际实现 9px/12）、标题 13px/16、左对齐、状态字形 14px 行内。
- 活动标签：同内容表面色 + 1px 分线色外框（底部不封口）+ 底部 16px 反向圆角弧接入分线。
- 状态字形：运行中=旋转弧、完成未读=实心点、需要你=气泡?/盾牌!/清单（回答/审批/计划评审），完成已读与空闲不显示。
- 动效：运行中 1.1s linear；需要你 2.2s/2.8s `cubic-bezier(.16,1,.3,1)`；完成未读 520ms `cubic-bezier(.34,1.56,.64,1)` 一次性；标签切换 180ms `cubic-bezier(.2,.8,.2,1)`。
